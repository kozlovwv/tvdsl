# Отчёт по HW3: типы и ограничения

## Типы

| Тип | Где |
|---|---|
| `int` | переменные, числа, арифметика, элемент массива, `length` |
| `int[]` | переменные; присваивание копирует массив, `a[i] = v` — функциональное обновление `Update` |
| `bool` | только условия и предикаты; переменных типа `bool` нет |
| `(T1, ..., Tn)` | вызов функции с `n > 1` возвратами; только в `x1, ..., xn = f(...)` |
| сигнатура функции | `(T1, ..., Tk) → (R1, ..., Rn)` из явных аннотаций параметров и возвратов |
| сигнатура формулы | `(T1, ..., Tk) → bool` |

## Правила

| Конструкция | Требования | Тип |
|---|---|---|
| `n`, `true`/`false` | — | `int` / `bool` |
| `x` | `x` объявлена и видна в этом месте | тип `x` |
| `a[i]` | `a : int[]`, `i : int` | `int` |
| `-e` / `not e` | `e : int` / `e : bool` | `int` / `bool` |
| `e1 + - * / e2` | оба `int` | `int` |
| `e1 == != < <= > >= e2` | оба `int` | `bool` |
| `e1 and or -> e2` | оба `bool` | `bool` |
| `length(e)` | один аргумент, `int[]` | `int` |
| `f(e1..ek)` в выражении | `f` — функция, `k` аргументов, `ei : Ti`, ровно один возврат | `R1` |
| `f(e1..ek)` в предикате | `f` — формула, `k` аргументов, `ei : Ti` | `bool` |
| `forall/exists (v:T \| p)` | `v` не совпадает с видимым именем, `p : bool` | `bool` |
| `x = e;` | `x` не параметр, тип `x` унифицируется с типом `e` | — |
| `a[i] = v;` | как `a = Update(a, i, v)`: `a : int[]`, `i, v : int`, `a` не параметр | — |
| `x1..xn = f(...);` | `f` возвращает ровно `n` значений, `xi` не параметры, тип `xi` унифицируется с `Ri` | — |
| условие `if`/`while`, `requires`, `ensures`, `invariant`, `assert`, `assume`, тело формулы | `bool` | — |

**Унификация.** Конкретные типы равны только сами себе. Переменная типа (тип локальной без аннотации)
привязывается к первому требуемому типу и запоминает позицию; две переменных связываются. Тип ошибки `?`
унифицируется со всем, чтобы не порождать каскад сообщений.

## Ограничения

- Нет перегрузок и приведений типов; `int` и `int[]` несовместимы, массивы нельзя сравнивать.
- Вывод типов — внутри одной функции и в порядке текста; локальная, тип которой ни одно присваивание или
  использование не задаёт, — ошибка. Типы параметров и возвратов не выводятся (по спецификации они обязательны).
- Не проверяются: инициализация перед чтением (по спецификации — неопределённое поведение), присваивание
  всех возвращаемых значений, выход за границы и деление на ноль (ошибки времени выполнения).
- В многозначном присваивании у AST одна позиция (первая цель), поэтому ошибки для всех целей указывают на неё
  и различаются именем переменной.
- Блоки не вводят областей видимости: объявлять переменные в блоке Funny не позволяет.
- Синтаксические ошибки останавливают обработку до семантических проверок (как в HW2).
